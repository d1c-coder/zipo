# ZIPO — futuristic agent network website

Static HTML/CSS/JS website inspired by the supplied Orbit reference screens, rebuilt around ZIPO's product concept.

## Included
- Animated desktop mega-navigation dropdowns
- Animated mobile navigation icon
- Futuristic agent execution console with animated routing particles
- Provider marketplace scene with live-style capability routing
- Reputation graph with connected agent/provider nodes
- Smooth FAQ accordion animation
- Responsive layouts
- ZIPO docs link: https://comp-6.gitbook.io/zipo
- Supplied cosmic hero artwork in `assets/hero-cosmic-v3.png`

## Run
Open `index.html` directly or serve the folder with any static server.
No framework or build step is required.
