# ZIPO website

A responsive, dynamic, Orbit-inspired single-page website for ZIPO.

## Files
- `index.html` — complete page
- `styles.css` — visual system, responsive layout and animations
- `script.js` — scroll reveals, tilt cards, mobile menu, FAQ accordion, timestamp and CA-coming-soon toast
- `assets/hero-cosmic-v3.png` — supplied hero artwork
- `ZIPO_Product_Concept.pdf` — supplied product concept, linked from the site

## Run
Open `index.html` directly, or serve the folder with any static server.

No framework or build step is required.
